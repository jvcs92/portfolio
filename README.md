# João Silva – Portfolio

Static portfolio site: plain HTML and CSS, no build step.

- `index.html` – home, with the three tracks
- `operations/` – operations cases
- `product/` – product & AI cases
- `partnerships/` – partnership cases
- `assets/styles.css` – shared styles (includes print styles for the PDFs)
- `assets/img/` – screenshots
- `pdf/` – one PDF per track, generated from the pages

Hosted on Cloudflare Pages, deployed automatically from this repository on every push to `main`.
